# pr-practice

Repository di prova per imparare a fare Pull Request.

## Cos'è questo repository

Questo repository serve per esercitarsi con il flusso di lavoro Git/GitHub:
creare un branch, apportare una piccola modifica e aprire una Pull Request.

## Come contribuire

1. Crea un nuovo branch a partire da `main`.
2. Apporta una piccola modifica (es. un miglioramento al README).
3. Apri una Pull Request descrivendo cosa hai cambiato e perché.
